# ► أدوات نظام التشغيل (System Tools)

::: tip
* **تحذير هام** - مش مِستحب تستخدم أدوات مسح برامج النظام (Debloaters) إلا لو كنت فاهم كويس إنت بتعمل إيه. دايماً دور واقرأ الأول، وأوعى تدوس "تطبيق الكل" (Apply All) بشكل عشوائي وخلاص.
:::

* [OfflineInsiderEnroll](https://github.com/abbodi1406/offlineinsiderenroll)، [2](https://gitlab.com/stdout12/offlineinsiderenroll)، [3](https://codeberg.org/stdout12/offlineinsiderenroll) - الاشتراك وتفعيل ميزة تحديثات ويندوز إنسيدر (Windows Insider) التجريبية بدون الحاجة لربط حساب مايكروسوفت
* [Rhasspy](https://rhasspy.readthedocs.io/en/latest/) - مساعد صوتي مجاني ومحترم للخصوصية ويشتغل بالكامل أوفلاين
* [OpenRecall](https://github.com/openrecall/openrecall) أو [Windrecorder](https://github.com/yuka-friends/Windrecorder/) - تطبيقات لتسجيل وحفظ كافّة أنشطة شاشتك لتقدر تبحث في تاريخ استخدامك وتلاقي أي حاجة شوفتها قبل كده (بديل حر لميزة Recall من مايكروسوفت)
* [Time.is](https://time.is/) - موقع للتحقق من دقة وقت وساعة جهازك ومزامنتها بالملي ثانية مع التوقيت العالمي

* [ASUS G-Helper](https://github.com/seerge/g-helper) - البديل الخفيف والسريع جداً لبرنامج Armoury Crate المزعج والثقيل للتحكم في لابتوبات أسوس (ASUS)
* [⁠PreySense](https://github.com/hammadzaigham/PreySense) - البديل البديل لبرنامج Armoury Crate المخصص للابتوبات آيسر بريداتور (Acer Predator)
