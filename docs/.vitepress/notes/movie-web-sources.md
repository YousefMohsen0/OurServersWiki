#### إضافة مصادر لـ P-Stream (وكل فروع movie-web)

تقدر تفعل إضافة: [Firefox](https://addons.mozilla.org/firefox/addon/p-stream-extension-v1/) / [Chrome](https://chromewebstore.google.com/detail/p-stream-enchanced/geimjiobahmbkmaigaafjnoanebpmlmj) / [script](https://github.com/xp-technologies-dev/userscript) هتضيف مصادر أكثر، لكنها محتاجة تتصل بكل المواقع عشان تشتغل. الإضافة آمنة، وناس كتير بتستخدمها، الصلاحيات مطلوبة عشان الإضافة تشتغل صح.

لاحظ إنك تقدر تشغلها في متصفح جديد أو بروفايل متصفح جديد لو مش عايز تستخدم متصفحك الأساسي.
